### Como eu trabalho

- **Escopo antes de código:** entendo a dor, escrevo o que vou construir e o que fica de fora, e só então construo.
- **Fluxo com agentes:** visão, execução, testes, revisão de segurança e histórico, cada etapa com um subagente do Claude Code.
- **Qualidade:** lint, typecheck, testes unitários e ponta a ponta, CI a cada push, migrations versionadas.
- **Segurança:** validação de entrada com Zod, sessão em cookie `httpOnly`, RLS no banco, segredos fora do git.
- **Entrega:** deploy na Vercel, projeto no ar com link, README que explica o problema, a stack e o porquê de cada escolha.
